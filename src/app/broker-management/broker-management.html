Setup Guide

Prepare your broker credentials.

  1. Open your broker developer portal

    Sign in to your broker's official account.

  2. Create or select an API application

    Follow the broker's current API setup instructions.

  3. Check the required credentials

    Confirm the App ID, API Secret and any other required values.

  4. Complete secure backend integration

    Credentials must be sent securely to the backend, never directly to a broker API from this page.
